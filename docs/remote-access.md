# 手机与浏览器远程访问

远程功能默认关闭，入口为「设置 → 远程访问」。开启后，手机浏览器可以查看并接管电脑端允许分享的终端；使用的是原会话，手机断开不会结束终端进程。

## 分阶段能力

| 阶段 | 已实现能力 |
| --- | --- |
| 1 · 查看 | 局域网 HTTP/WebSocket、一次性扫码配对、选择分享会话、当前画面与增量同步、断线重新同步 |
| 2 · 接管 | 全局默认与会话例外、默认只读、单设备控制、中文与多行草稿、辅助按键、电脑收回、断线释放控制权 |
| 3 · 公网 | Cloudflare Tunnel 与 ngrok、按需下载官方客户端、Windows 凭证保护、可选创建 Cloudflare 隧道与 DNS |

## 与已安装版本并行试用

在仓库根目录运行：

```powershell
npm ci
npm run dev:remote
```

该命令使用独立应用标识 `io.github.suncodes.sterm.remote-dev`，隔离工作区、偏好、凭证与 WebView 存储。它不会更新安装目录或重启已安装版本。终止开发命令只会结束开发版及其终端。

已有安装版进程不会获得新增功能。请在开发版新建测试会话；不要为了试用关闭正在工作的旧会话。

## 局域网扫码

1. 在开发版创建终端，进入「设置 → 远程访问」。
2. 点击「开启远程访问」。高级选项默认允许局域网连接，端口为 `8765`，占用时可在开启前修改。
3. 默认自动分享运行中的会话，只允许查看。需要输入时，在「会话权限」开启「默认允许输入」，或为单个会话选择「允许接管」。
4. 在「连接 → 局域网」选择手机可访问的电脑局域网 IP，扫码自动生成的二维码。
5. 在手机点击「接管」后输入，或点击「归还」恢复电脑输入。电脑端始终可以「收回控制」。

二维码不依赖公网：先开启远程服务，再为当前地址生成二维码。公网配置成功后，可以选择 HTTPS 地址生成新的二维码；切换地址需要重新配对。

二维码五分钟内有效且只能使用一次。成功配对后的浏览器凭证有效期为十二小时；刷新页面不需要重新扫码。「连接 → 管理」可以撤销全部设备，关闭远程访问或退出应用也会撤销全部浏览器授权，之后需要重新扫码或使用已设置的访问码登录。最多支持八个配对浏览器。

## 长期访问码

二维码与访问码登录可以同时使用。进入「设置 → 远程访问 → 连接」，开启「访问码登录」，输入一次 6 位数字访问码后保存。访问码保留至修改或关闭；应用重新启动后仍可使用，远程访问本身仍需手动开启。

保存后默认以圆点隐藏，可点击「显示／隐藏」「复制」「修改」。切换设置页或关闭设置会重新隐藏。查看和复制不撤销设备授权；修改或关闭访问码仍会撤销全部设备。复制会将访问码写入系统剪贴板。

旧版只保存不可逆校验值，原访问码仍可登录，但无法查看或复制；重新设置一次即可启用查看功能，也可以继续使用原来的 6 位数字。

1. 连接 ngrok 或 Cloudflare，切换到「连接 → 公网」。
2. 点击「复制地址」获取不带一次性配对凭证的基础地址，可收藏此地址。
3. 在手机或浏览器打开该 HTTPS 地址，输入访问码后点击「进入」。
4. 登录只授予查看已分享会话的资格；输入仍需电脑允许，并由远程端主动接管。

访问码登录仅支持 HTTPS 公网地址。局域网 HTTP 页面继续使用二维码，避免长期访问码在明文连接中传输。若公网地址变化，需要使用新的地址；设置访问码不会让隧道自动常驻或固定 ngrok 域名。

| 登录方式 | 凭证有效期 | 浏览器授权 |
| --- | --- | --- |
| 二维码／配对链接 | 5 分钟、一次性 | 配对成功起 12 小时 |
| 6 位访问码 | 保留至修改或关闭 | 登录成功起 30 天 |

浏览器授权为固定期限，不因操作自动续期；只在当前远程服务运行期间有效。刷新页面或短暂断网可复用有效 Cookie；关闭远程服务或退出应用后，旧浏览器授权失效，重新开启后输入原访问码即可登录。「撤销全部设备」清除二维码与访问码登录的全部设备授权和未使用票据，保留访问码配置。修改或关闭访问码同样立即撤销全部设备，正在查看的网页返回登录页。

访问码验证使用随机盐和 PBKDF2-HMAC-SHA256（600,000 次）。校验信息与可恢复的访问码一起通过统一凭证保护接口，使用当前 Windows 用户的 DPAPI 加密，保存在 %LOCALAPPDATA%\io.github.suncodes.sterm\remote-auth\password.credential，磁盘不保存明文。访问码原文仅通过电脑端设置窗口的主动显示或复制操作返回，配置查询、状态轮询和远程 HTTP 接口均不返回原文；访问码不写入 URL、浏览器 localStorage 或诊断日志。访问码登录 Cookie 为 HttpOnly、Secure、SameSite=Strict；公网服务仍终止 HTTPS，沿用现有隧道信任边界。

服务端每个连接来源 5 分钟最多接受 5 次访问码尝试，全局 10 分钟最多 30 次，成功、失败与正在校验的请求均计入；最多并行校验 2 次。超限返回 429 和重试时间，网页显示倒计时；刷新网页不能绕过服务端限制。经隧道转发的请求可能共享同一本机来源，因此限流可能合并计算，不信任任意代理 IP 请求头。二维码配对保留原有限制，最多同时保留 8 个浏览器授权。

## 默认权限与会话例外

首次默认为「默认分享会话」开启、「默认允许输入」关闭。默认设置保存在本机，下次打开应用继续使用；远程服务每次启动应用后仍需手动开启。

| 会话规则 | 行为 |
| --- | --- |
| 跟随默认 | 当前与新建、重启的会话依据全局默认自动分享和允许输入 |
| 不分享 | 浏览器不可查看 |
| 只读 | 独立于全局默认分享，禁止输入 |
| 允许接管 | 独立于全局默认分享，手机主动接管后可输入 |

修改默认权限立即影响所有「跟随默认」会话，保留单独例外。降低输入权限或取消分享会立即收回控制权。单会话规则随该标签保留，重启其 Shell 或关闭再开启远程服务不丢失；关闭标签或退出应用后结束，新标签重新跟随默认。应用不恢复已经退出的终端进程。

输出积压或同步失败时，会话会暂停分享，本地终端继续运行。在「会话权限」重新选择该会话的规则可恢复分享。

局域网使用 HTTP，仅用于可信网络。手机和电脑需互通；访客 Wi-Fi、客户端隔离、VPN 网卡或 Windows 防火墙可能影响访问。若系统提示防火墙授权，可仅允许可信的专用网络；sTerm 不会自动修改防火墙规则。地址列表中 `127.0.0.1` 和 `localhost` 仅供电脑自身测试。

## ngrok：快速公网测试

1. 注册 ngrok 账号，在控制台获取 **Authtoken**。
2. 在「设置 → 远程访问 → 公网」选择 ngrok，填入 Authtoken，点击「连接 ngrok」。也可先「保存配置」再连接。
3. 首次自动下载并校验官方 Windows 客户端，之后复用本地文件。
4. 等待公网连接成功，切回「连接 → 公网」，选择地址并扫码。

无需自备域名、API Key 或安装手机客户端。免费套餐的提示页、流量与请求限制由 ngrok 决定；手机首次打开时可能需要先通过提示页。

### 会话额度、清理与复用

ngrok 的在线 agent session 是客户端进程与 ngrok 云端的连接；sTerm 的多个终端会话和手机共用同一条隧道，不会各占一个 agent session。`ERR_NGROK_108` 表示账号的同时在线 agent 数量达到上限，具体上限以账号套餐为准。

- 同一 sTerm 实例对相同服务商和监听端口重复发起连接时复用当前进程；同一数据目录通过系统文件锁避免多个实例重复启动。
- 启动隧道前自动检查本版本组件目录的遗留进程，仅终止父进程已退出且可执行文件路径匹配的 ngrok/cloudflared。仍由其他实例管理、其他目录或其他电脑的进程不在清理范围内。
- 断开时等待隧道进程退出后再清除连接状态；停止失败会保留可重试的状态和错误信息。关闭远程服务、正常退出应用会停止当前组件；Windows Job Object 同时负责应用被强制结束时的子进程清理。
- ngrok 的公网设置提供「清理遗留连接」，可在未连接时使用。连接被拒绝或首次连接超过 45 秒仍未成功时会停止组件并显示原因，不循环创建新 agent。
- 新启动的 ngrok 开启官方 `remote_management`，支持在 [ngrok Agents 控制台](https://dashboard.ngrok.com/agents) 执行 Stop。旧版设置为 `false` 的进程需要先在本机结束，修改配置文件不会更新已运行进程。云端状态同步可能稍有延迟。

如果清理后仍报额度不足，请在控制台检查其他版本、终端或设备启动的 agent；sTerm 无需额外 API Key，也不会批量停止账号内的其他会话。手动排查时先用任务管理器或 `Get-CimInstance Win32_Process` 查看 ngrok 的 PID 与可执行文件路径，再停止确认属于遗留连接的进程。

官方说明：[ERR_NGROK_108](https://ngrok.com/docs/errors/err_ngrok_108)、[remote_management](https://ngrok.com/docs/agent/config/v3#remote-management)。

## Cloudflare Tunnel：固定公网地址

固定域名模式需要 Cloudflare 账号以及已由 Cloudflare 管理且激活的域名，仅有账号不足以完成此模式。推荐使用专用一级子域名，例如 `sterm.example.com`。

### 使用控制台已有隧道

1. 在 Cloudflare 控制台创建 remotely managed Cloudflare Tunnel。
2. 配置 Public Hostname，将 `sterm.example.com` 指向 `http://127.0.0.1:8765`；如果更改本地监听端口，需同步修改该路由。
3. 获取隧道的 **Tunnel Token**。不要粘贴整条安装命令。
4. 在「设置 → 远程访问 → 公网」选择 Cloudflare，填写 Token 与 `https://sterm.example.com`，点击「连接 Cloudflare」。
5. 组件连接成功且域名路由可用后，用该 HTTPS 地址生成二维码。

### 由 sTerm 创建隧道与 DNS

展开「自动创建 Cloudflare 隧道与 DNS」，填写新主机名与临时 API Token。Token 需有目标域名的 **Zone Read、DNS Edit** 和目标账号的 **Cloudflare Tunnel Edit** 权限。

sTerm 会检查域名状态及 DNS 冲突，然后创建隧道、配置本地服务路由、创建代理 CNAME，并保存运行用的 Tunnel Token。已有 DNS 记录会拒绝覆盖。API Token 仅用于本次操作，不保存到磁盘。

创建成功后点击连接即可；后续使用已保存的运行凭证，无需重复创建。Cloudflare Access 登录策略需要在控制台自行配置。创建中途失败时，错误信息会说明可在控制台补完的步骤；关闭远程功能不会删除账号中的隧道和 DNS。公网连接状态表示客户端已连接，域名路由和 Access 策略仍需首次实际访问确认。

## 输入、画面与运行限制

- 手机默认查看；电脑允许输入后，仍需手机主动接管。接管期间电脑键盘输入暂停，终端协议响应继续工作。
- 手机会话栏只展示当前会话，通过右侧列表切换；宽屏浏览器显示会话标签，窄屏采用手机布局。
- Agent 状态以电脑端为准：黄色脉动「运行中」、绿色「空闲」、红色「已退出」，无 Agent 时隐藏状态标记。手机当前会话、右侧列表与宽屏标签同步显示状态文字，与「只读／可接管／控制中」权限信息分别展示；首次连接和重连恢复最新状态。识别范围与电脑端一致。
- 草稿按会话保存在当前网页内存中，切换会话和连接中断时保留。点击「发送」或 Ctrl+Enter 才写入终端，普通 Enter 换行，可控制是否追加回车；中文输入法候选确认不会误发。发送按钮固定为 72×44px。发送后清空草稿，断线不会自动重发。刷新页面、会话结束后草稿不保留，单次输入最多 8 KB。
- 输入框下方「历史」或右上显示菜单的「历史命令」可查看最近 100 条远程发送内容。列表只展示命令，支持按内容搜索、点击回填、行末删除与确认清空，不展示时间和来源会话；长命令最多预览两行，回填时保留完整内容。重复内容按最近发送时间置顶，保留中文、多行与原始空格，辅助按键和空白输入不记入历史。记录表示浏览器已提交发送，不表示终端已经接收或执行成功。
- 接管后点击历史内容会回填到当前会话输入框，不会自动执行；可修改后手动发送。覆盖草稿后可「撤销回填」，恢复回填前的草稿；手动编辑或发送后结束本次撤销。历史在同一访问地址下跨会话共用，通过浏览器 localStorage 保存，刷新后仍保留；不同浏览器、设备、局域网和公网地址分别保存。存储被禁用或空间不足时，当前页面仍可使用历史。电脑端收回控制、断线或降权后禁止回填和发送，仍可浏览和删除本浏览器历史。
- 快捷键栏支持 Esc、Tab、Ctrl 修饰、退格（Backspace）、Delete、Enter 和方向键；窄屏分为两行，更多面板包含 Ctrl+C/D/L、Shift+Tab、Home/End 和翻页。删除键和方向键支持长按连发，松手、滑出按钮、取消触摸、切换页面、切换会话、断线或失去控制权时停止；Enter 只发送一次回车，草稿为空时也能确认终端中已调出的内容。快捷键直接操作终端，不修改网页输入框中的草稿，也不记入历史命令。只读时收起输入与快捷键。
- 修改终端中通过 ↑ 调出的历史内容时，可用左右方向键定位，再用退格或 Delete 删除。需要补充文字时，取消勾选「追加回车」，在输入框填写片段后发送；检查后按快捷栏 Enter 提交。也可以继续用「历史」回填完整内容到网页输入框，修改后再发送。
- 每个会话同时只有一个控制者。手机切换会话、归还或断线会释放控制权；网络异常会在心跳超时后释放。
- 默认保持电脑终端尺寸，可在右上显示菜单调整字号；控制者可开启「适配屏幕宽度」或「立即适配当前尺寸」，该操作也会改变电脑端终端尺寸。归还后恢复电脑布局。
- 新连接和重连恢复当前终端画面及最多三百行回滚，再接收增量；这不是完整终端历史存档。
- 会话退出或取消分享会撤销该会话的远程访问；重启 Shell 时撤销旧进程控制权，再按该标签的权限分享新进程。配对浏览器可以看到所有当前允许分享的会话。
- 电脑必须保持开机、联网且 sTerm 运行。首版不提供系统服务、开机自启或关闭应用后继续运行的终端。
- Cloudflare/ngrok 客户端处理临时网络重连；客户端进程退出后，请在面板重新连接。

两个隧道客户端都不随安装包分发，只在首次点击连接时下载到当前版本的用户数据目录。远程功能代码及依赖本身仍会增加程序体积。
