# 远程访问界面调整 · V2

记录时间：2026-11-17。用户已确认原型，正式源码已按设计迁入；使用独立开发版验证，未更新安装版或 Release 打包产物。

## 用户反馈与已确定要求

- 新增界面与 sTerm 现有风格不一致，需要重做电脑端和网页端界面。
- 远程访问入口移入设置，去掉标题栏独立手机入口。
- 支持统一设置默认分享、默认允许输入，新建会话不再逐个勾选。
- 优先复用现有设置双栏、导航项、开关、按钮、字号、间距和深色主题。
- 网页端需重新设计会话 Tab、快捷键、输入框和终端显示。
- 先完成界面方案审查，再继续详细功能测试。
- 发送按钮使用固定尺寸，避免随多行输入框高度拉伸。
- 手机端默认仅显示当前会话，只通过右侧会话列表切换；宽屏浏览器保留多标签。

可直接打开 [交互原型](prototypes/remote-access.html)。原型使用仓库现有 `src/style.css` 中的设置和主题样式，所有演示状态只保存在页面内存中，不访问终端、不填写真实凭证、不调用公网服务。

用浏览器打开 HTML 后，可在页面顶部切换「电脑端 / 手机端 / 浏览器 / 并排」，并用「手机状态」查看只读、可接管、控制中和断线。原型初始开启远程访问仅为展示页面；正式版首次仍保持总开关关闭。原型二维码和复制链接只使用 `example.invalid` 演示地址，刷新仅演示交互。公网连接按钮不校验凭证，不会实际启动隧道；请勿填写真实 Token。

## 电脑端方案

入口为「设置 → 远程访问」，沿用设置左侧分类。右侧顶部保留远程访问总开关、状态及次级页签：

| 页签 | 内容 |
| --- | --- |
| 连接 | 局域网/公网地址、二维码、链接复制、连接状态；端口与局域网监听收进高级选项 |
| 会话权限 | 默认分享、默认允许输入、跟随默认的解释、当前会话例外；提供新建示例会话以验证继承 |
| 公网 | Cloudflare/ngrok 切换、状态、必要凭证及连接按钮；首次 Cloudflare 配置收进展开项 |

总开关关闭时仍可预设默认权限和公网配置。配对操作在开启后可用；关闭后同步撤销访问。二维码始终属于所选地址，不以公网连接为前提。

视觉使用现有 charcoal 灰阶、4px 控件圆角、12–14px 字体、蓝色主操作、原生可访问开关。主体以行、分隔线和紧凑操作组织，避免大段说明和满宽按钮。设置窗口在原有双栏基础上适度增加内容高度；小屏自动缩放并允许内容滚动。

## 权限语义

首次默认：远程访问关闭；新会话默认分享开启；默认允许输入关闭。用户可以一次开启默认允许输入，之后不再逐个授权。

| 会话设置 | 实际行为 |
| --- | --- |
| 跟随默认 | 依据全局默认分享及输入权限自动变化，新建会话使用此项 |
| 不分享 | 浏览器不显示该会话 |
| 只读 | 可查看，禁止远程接管 |
| 允许接管 | 手机主动接管后可输入 |

- 修改默认权限立即影响所有「跟随默认」的当前会话和以后新建的会话。
- 单独设置不被默认值覆盖；选回「跟随默认」可恢复继承。
- 默认分享关闭时，默认输入开关不可操作；会话的显式「允许接管」仍独立生效。
- 输入权限不等于已经接管，继续保留单控制者、电脑收回、断线释放以及不自动重发输入。
- 某会话有效权限降低或取消分享时，立即收回其现有远程控制权。
- 全局默认持久化在本机；会话规则随终端标签保留，重启 Shell 或关闭再开启远程服务不丢失。关闭标签或退出应用后结束；应用不恢复终端进程，新标签重新继承默认，避免把旧标签的输入权限误授予无关会话。已有手动设置迁移为单独规则。

## 手机与浏览器方案

- 顶部轻量连接栏，保留重连/显示菜单；连接、只读、控制中均有文字标识。
- 手机会话栏只展示当前会话名称与状态点，长名称截断；右侧列表按钮打开会话侧栏，选中后关闭侧栏并更新当前会话，保留各会话草稿。
- 宽屏浏览器保留横向会话 Tab 和右侧会话列表；窄屏浏览器采用与手机相同的单会话栏。
- 终端占据主要空间，沿用纯黑底与等宽字体。需要横向浏览时仅终端内部滚动；字号和适配入口收进显示菜单。
- 只读时收起输入区，展示明确的接管入口及权限说明；控制期间显示归还操作。
- 控制时展示紧凑输入框，支持中文、多行、显式发送、是否追加回车；Ctrl+Enter 发送，普通 Enter 换行。
- 发送按钮统一为 72×44px 的长方形文字按钮，仅显示「发送」，固定在输入框右下侧；输入框增高时按钮尺寸不变，保留「发送输入」可访问名称与快捷键提示。
- 常用 Esc / Tab / Ctrl / 方向键保持一行；更多组合键在展开面板中。Ctrl 修饰状态可见，禁止只读时发送。
- 手机使用至少 44px 点击区域，适配安全区与软键盘；横屏/宽浏览器沿用相同组件，让终端获得更多空间。
- 原型提供只读、可接管、控制中、断线四种状态，以及电脑/手机/浏览器/并排视图。

## 正式迁入范围

电脑端沿用现有设置组件与主题变量，接入连接、会话权限、公网页签及设备撤销；网页端复用现有 xterm 和真实 WebSocket 协议，实现响应式布局、会话侧栏、快捷键及草稿。未增加新的运行依赖，Cloudflare/ngrok 继续按需下载。

原型继续保留供对照。真实手机软键盘与公网账号连接仍需设备和账号条件确认；本次未改动本机正在使用的安装版，也未覆盖 Release EXE。
