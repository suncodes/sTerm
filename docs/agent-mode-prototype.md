# Agent 模式交互原型

[打开交互原型](prototypes/agent-mode.html) · [查看静态预览](prototypes/agent-mode-preview.png)

使用 Google Chrome 打开 docs/prototypes/agent-mode.html，无需安装依赖、运行 sTerm 或提供 API Key。默认并排展示宽屏网页和手机，顶部可切换「手机端 / 宽屏网页 / 电脑端 / 并排」。手机预览宽度可选 360、390、430 px。

本次交付用于评审界面、状态和操作流程。所有内容、模型、工具结果与交互均为模拟数据，仅保存在页面内存中；刷新即可恢复。没有连接真实 Agent，没有启动 Agent 服务，也没有更改安装版 sTerm 的程序、配置或会话。

## 网页端方案

沿用现有 sTerm 的灰阶主题、连接栏、4 px 控件圆角及会话导航。Agent 模式采用消息排版，手机宽度不会改变电脑终端尺寸。

- 手机顶部仅显示当前会话；右侧列表打开会话抽屉。宽屏保留横向 Tab。
- 会话来自电脑端已接入且获准分享的 Claude Code / Codex，不要求手动填写会话 ID。
- 消息区区分用户输入、Agent 回复、思考摘要、工具结果及文件变更；工具结果可展开。
- 模型和 Agent 权限使用选择面板；实际选项需根据 Agent 的能力提供。
- 审批卡片固定在输入区上方，包含操作对象、详情、拒绝和批准一次。
- 生成时显示「停止生成」；追加消息单独显示待处理状态。
- 输入框支持多行、中文和 Ctrl/Cmd + Enter 发送；发送按钮固定 72 × 44 px。
- 每个会话分别保存网页草稿；断线保留草稿，恢复连接后不自动重发。

「Agent 权限」表示工具执行范围；「网页只读」表示远程端能否操作。这是两个不同的设置。例如 Agent 使用只读执行策略时，用户仍可输入要求。

## 预置演示状态

| 顶部状态 | 可查看的行为 |
| --- | --- |
| 空闲 | 消息、文件变更、模型选择、权限选择与发送 |
| 实时输出 | 分段打印、停止当前回合、追加要求 |
| 等待审批 | 详情、批准一次或拒绝；另一侧同步关闭待办 |
| 追加消息 | 待处理消息提示与列表 |
| 只读 | 保留消息，收起输入区并禁用控制操作 |
| 断线 | 保留内容和草稿，重连后继续 |
| 操作失败 | 模型切换失败提示，原模型保留 |
| 已结束 | 保留内容，禁止继续输入 |
| 无会话 | 引导用户在电脑终端使用 Agent，无需填写 ID |

「实时输出」会停留在运行状态，便于体验停止和追加；顶部「演示本轮完成」用于观察完成状态。它是评审控制，不属于产品页面。「重置」重置当前场景，刷新页面可同时清空草稿。

## 推荐演示顺序

1. 保持「并排」，在手机右侧会话列表切换 Claude / Codex，输入草稿后切换回来。
2. 选择「空闲」，点击模型和锁形权限菜单，观察后续操作的选择方式。
3. 选择「实时输出」，发送补充要求，查看追加列表，再点击「停止生成」。
4. 选择「等待审批」，打开详情，然后批准或拒绝。
5. 切到「电脑端」，选择「等待审批」，在终端示意区审批；再切回手机查看结果。
6. 在电脑端输入演示文本并按 Enter，再切回网页查看同一会话。
7. 打开电脑端「分享设置」，将当前会话改为「仅查看」或「不分享」，观察网页变化。
8. 选择「无会话」，点击电脑端上方「演示终端启动 Agent」，观察会话出现。
9. 在消息输入草稿后选择「断线」，点击重连，观察草稿保留且没有发送。

并排视图以及电脑、网页预览共用同一个演示数据源，选择会话也会一起切换，便于对照评审。正式产品中，各端应独立选择正在查看的会话；同一会话的消息、审批和执行状态同步。

## 电脑端方案

保留工作区、终端 Tab、黑色终端、原生 CLI 使用方式和状态栏；仅增加紧凑的 Agent 接入与分享状态。终端区域的输入和审批按钮仅用于模拟双端操作，不代表替换原生 CLI。

分享设置复用「设置 → 远程访问 → 会话权限」：

- 默认分享及默认允许网页操作统一设置。
- 当前会话可选「跟随默认 / 允许操作 / 仅查看 / 不分享」。
- 默认变化影响跟随默认的会话，单独设置继续保留。
- Agent 模式允许电脑与网页同时操作，不引入接管、归还流程。
- 自动接入说明放在「设置 → 集成」，不添加独立 Agent 启动管理页。

原型为方便演示，默认打开分享和网页输入；正式产品沿用已有远程访问设置与首次默认值，不以原型的初始状态覆盖用户配置。远程总开关、公网配置及历史恢复入口仅展示位置，不连接服务或恢复真实历史。

## 三种停止操作

| 操作 | 入口 | 作用 |
| --- | --- | --- |
| 停止生成 | 输入区上方 | 中断当前回合，保留会话 |
| 结束 Agent 会话 | 更多 → 结束会话 → 确认 | 演示结束电脑端的 Agent，网页保留内容 |
| 停止分享 | 电脑端会话权限 → 不分享 | 撤销网页访问，电脑端继续使用 |

「结束会话」的确认只针对模拟数据，不会终止本机程序。

## 实施边界

自动识别与接入终端会话、保留原生 CLI 的双端控制、结束整个 Agent 进程、模型和权限动态列表均为目标体验。原型通过界面呈现这些流程，不代表当前正式代码已经全部实现，也不代表可以无条件接管任意已启动的 Claude / Codex。

后续实现需逐个验证 Claude Code / Codex 的本地接入方式、CLI 版本、审批与中断能力。只展示实际支持的控制项；模型名称和思考摘要也以 Agent 实际提供的数据为准。本轮不处理 Pi。

## 验证记录

已使用独立 Google Chrome 验证本地 HTML 加载与主要交互：会话与草稿、模型和权限、双端模拟输入和审批、停止、追加、断线、分享规则、结束会话及自动接入演示。手机 360 / 390 / 430 px、768 px 网页布局均无页面横向溢出。

原型结构仅包含评审外壳、展示页面、模拟状态与样式，复用现有主题；不引入前端框架、Agent SDK 或正式服务依赖。手机软键盘、真实网络重连、真实 Agent 并发控制仍需在功能实施阶段验证。
